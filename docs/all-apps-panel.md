# 全部面板

Flyme 小窗是面向 ColorOS 的非官方独立实现，与魅族、Flyme、OPPO 或 ColorOS 无关联。

## 独立窗口与系统内容

扇形选择“更多”后，模块在智能侧边栏 UI 进程中创建独立窗口，承载一个新建的系统“全部”内容视图。原侧边栏保持收起，不调用展开侧边栏或模拟点击“全部”的入口，也不改写其父面板状态。

工具、应用、快捷方式、图标、文字、排序、工具折叠及搜索均由已安装的系统包提供。模块不将系统 APK、厂商资源或反编译代码打包分发。点击仍调用该内容视图原有的点击回调，由 ColorOS 决定工具行为、分身用户、快捷方式和应用打开方式。

适配范围为 Android 16、智能侧边栏 16.14.6（160014006）。运行时核对系统包身份、受保护的服务和 Provider、类及方法签名；需要开启智能侧边栏及其模块作用域。新增该作用域是为了在拥有原厂数据和执行权限的进程中承载面板，不向所有应用注入。

## 打开与执行

通过受权限保护的系统 Provider 请求建立常驻端与 UI 端连接，再以带版本、请求标识、期限和 UID 校验的 Messenger 进行交接。准备最多等待 7 秒，窗口打开最多等待 3 秒。原厂初始化、列表加载和图标处理留在原进程；跨进程只发送少量控制消息。

已安装系统不支持、侧边栏关闭或桥接未加载时可回退原有内置应用网格。打开请求发出后，只有确认窗口已经清理才允许回退；不确定时结束请求，不叠加第二个面板。

独立窗口从缩小状态进入，内容单独淡入，关闭时围绕自身中心缩小并淡出。挂载前先确定面板尺寸和位置；首帧等待 Insets、实际布局和模糊背景区域全部就绪，避免左上角占位内容提前绘制。桌面始终由扇形窗口保留的同一层 0.1 遮罩覆盖，全部窗口不创建第二层遮罩，避免交接空帧。入场期间面板外壳保持不透明、材质模糊使用最终参数，避免面板底色透黑后逐渐变亮。退场使用原厂可核对的临界阻尼参数：alpha 周期 0.3 秒，scale 周期 0.4 秒且终点为 0.3。阴影、圆角和可用时的材质模糊复用系统实现，系统动画关闭时直接落到终态。独立窗口的整体入场并非原厂“侧栏展开为全部”的形变动画。

应用点击沿用原厂先发起启动、再退出面板的调用次序。工具点击先让面板完全不可见，再等待系统端确认桌面遮罩的透明帧已经提交，随后执行原有回调，以免截图包含面板。动画期间重复点击被忽略；执行前按条目标识重新定位，避免列表刷新后使用过期索引。

## 生命周期与验证边界

窗口、搜索订阅、动画、返回回调、配置与广播监听由本次会话拥有。关闭、锁屏、用户切换、配置变化、服务销毁或系统自行展开侧边栏时结束会话；待执行工具在取消后不会继续触发。键盘出现时约束窗口可用区域。入口仅服务当前前台用户和默认显示，不跨用户复用回退目录。

协议交接、几何边界、退场曲线和点击执行顺序有 JVM 单元测试。类签名和资源来自当前目标设备上同一 SHA-256 的系统 APK。目标设备已人工确认基本打开、关闭、应用点击启动、背景亮度与首帧显示。搜索输入、全部工具、应用冷/热启动组合、长按分屏及折叠屏行为仍待逐项验收。
